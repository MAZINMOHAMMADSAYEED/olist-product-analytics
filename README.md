# Olist E-commerce Product Analytics

Analysis of the Brazilian Olist e-commerce dataset (about 99K orders) using SQL (DuckDB) and Python.

**Status:** in progress

## Questions
- How do orders and revenue grow over time?
- How many customers come back, and why?
- How much does late delivery hurt review scores?

## Data
Download from Kaggle: "Brazilian E-Commerce Public Dataset by Olist" and place the CSVs in `data/raw/`.
